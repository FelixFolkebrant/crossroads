04

Autonomous choices

Late and delegated decisions

Hard-to-reverse choices discovered after approval and Hot choices made during the unattended build.

L1

Preserve the active GH-003 branch

Accepted at Gate 2

The one-shot default-branch convention conflicted with the accepted template and asset work already present as user-owned changes on felixf/GH-003/0.

Choice

Remain on the current branch, commit only one-shot-owned files, and leave every pre-existing modification unstaged.

Why

Switching branches or absorbing unrelated work would have risked the exact visual inputs and violated the explicit Gate 2 readiness agreement.

L2

Keep distribution local and unlicensed

Delegated by C5

Local VSIX packaging exposed a licensing choice even though publishing and distribution were outside the accepted scope.

Choice

Set the package to UNLICENSED, produce a local VSIX, and do not publish or grant distribution rights.

Why

Granting no new rights has the lowest reversal cost. The user can select a license deliberately before any future publication.

H4

Bundle the runtime dependency

Delegated during build

The extension needed a parser and a package shape that would work without runtime installation.

Approach

Use TypeScript, markdown-it@14.3.0, and esbuild; bundle the parser into one CommonJS extension entry point while excluding tests and source maps from the VSIX.

Review consequence

The seven-file package is self-contained and the dependency audit is clean; changing the build tool or parser later remains affordable.

H5

Let Framework components grow with Markdown

Delegated during build

The exact reference CSS used fixed heights for example copy, while generated canonical sections can contain more content.

Approach

Keep the accepted reference dimensions as minimum heights, preserve every visual token, and allow repeated cards and Markdown content to expand or stack responsively.

Review consequence

Short reference content retains the designed geometry; long content remains visible instead of clipping. The responsive issue-tab selector was also corrected.
