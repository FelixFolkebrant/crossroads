Lets build a vs code extension that allows us to take a markdown file ([GH-XXX.md](docs/templates/GH-XXX.md) or [PP-X.md](docs/templates/PP-X.md) ) and when I press crl+alt+shift+v it renders to an html file ([PP-X.html](docs/templates/PP-X.html) [GH-XXX.html](docs/templates/GH-XXX.html) ). The markdown file should be the single source of truth and I think that we should try to keep as much of markdown as possible and not introuduce any new tags or things. That would mean that the renderer would have to use headings and other format things to read the html file. We do not need full support for all markdown things but only for the things that we can anticipate inside of an issue or planpoint. We can modify the markdown templates if needed but I feel like they are good where they are right now. It should use the EXACT design that we have made into the current html templates. The extension should work like the vs code markdown viewer where you toggle between rendered markdown.
